# Authentik SSO – Tài liệu triển khai

Tài liệu hướng dẫn cài đặt Authentik bằng Docker Compose trên Ubuntu Server, ghi nhận cấu hình thực tế tại máy chủ `mstarcorp`.

## Tài liệu

- [Tài liệu cài đặt Authentik SSO (Word)](./Tai-lieu-cai-dat-Authentik-SSO.docx)
- [Tài liệu cài đặt Authentik SSO (Markdown)](./Tai-lieu-cai-dat-Authentik-SSO.md)

## Trạng thái

- Cài đặt Authentik và truy cập Application Dashboard: hoàn tất.
- Tạo Provider/Application cho Synology: chưa thực hiện.
- Tích hợp DSM: chờ xác minh model NAS và phiên bản DSM.

> Lưu ý: Không đưa file `.env`, secret key, mật khẩu hoặc bản dump database chứa dữ liệu định danh vào repository.
